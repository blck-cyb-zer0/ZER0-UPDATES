Free Subtitle Downloader: Find English Subtitles for Your Video Files Automatically

Find English subtitles for the video files in a folder, using the subliminal library.

What it does

Looks for video files (mp4, mkv, avi, mov, webm) in the same folder as the script, searches for English subtitles with the subliminal library and saves the best match next to each video.

How to use it

  1. Install Python 3, then run pip install subliminal.
  2. Put the script in the same folder as your video.
  3. Make sure the file name looks like the title, for example Movie.Name.2020.1080p.mkv.
  4. Run the script. The .srt file appears next to the video.

Requirements

Python 3, the subliminal library and an internet connection.

Good to know

  • English only.
  • Results depend on the file name. Messy names find fewer matches.
  • Subtitle sites sometimes limit requests, so a miss does not always mean no subtitle exists.
  • Always check that the subtitle matches your version of the video.
