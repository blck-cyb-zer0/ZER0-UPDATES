Free Bulk Image Compressor: Shrink JPG, PNG and WebP Photos in One Run

Shrink a whole folder of JPG, PNG and WebP pictures in one run, with three quality levels.

What it does

Reads every JPG, PNG and WebP in a folder called images, saves a smaller copy of each into a folder called compressed, and prints the before and after size. Your originals are never touched.

How to use it

  1. Install Python 3, then run pip install Pillow once.
  2. Put the script in any folder and run it once. It creates an images folder.
  3. Copy your pictures into images and run the script again.
  4. Pick 1 (smallest, quality 60), 2 (quality 80) or 3 (quality 90, the default).
  5. Collect the results from the compressed folder.

Requirements

Python 3 and the Pillow library (pip install Pillow).

Good to know

  • Large phone and camera photos shrink a lot. Images that are already optimised barely change.
  • The quality setting mainly affects JPEG. PNG files are re-saved with optimisation but will not shrink as much.
  • Pictures with transparency are converted to a solid background, so transparency is lost.
  • Only the top level of the images folder is read, not sub-folders.
