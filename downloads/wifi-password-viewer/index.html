ZERO WiFi Password Viewer

Python version of the Wi-Fi password viewer: lists saved networks on Windows and Linux.

Type: Python scriptWorks on: Windows, LinuxVersion: 1.0Size: 1.6 KBPrice: Free

Download ZERO-WiFi-Password-Viewer.py

What it does

On Windows it prints the name and password of every Wi-Fi network saved on the PC. On Linux it lists the saved network files from NetworkManager and tells you the command to read a password with sudo.

How to use it

  1. Install Python 3.
  2. On Windows, open Command Prompt as administrator and run python ZERO-WiFi-Password-Viewer.py.
  3. On Linux, run the script, then use sudo cat on the file it names to read a password.

Requirements

Python 3. Administrator (Windows) or sudo (Linux) to read passwords.

Good to know

  • On Linux the script lists names only. Reading the password itself needs the sudo command shown at the end.
  • It does not work on phones.
  • Only use it on your own computer.
  • If you only need Windows and do not want to install Python, use the batch file version.
