ZERO WiFi Password Revealer

Show the passwords of Wi-Fi networks your Windows PC has already saved.

Type: Windows batch file (.bat)Works on: WindowsVersion: 1.0Size: 600 BPrice: Free

Download ZERO-WiFi-Password-Revealer.zip

What it does

Uses the built-in Windows netsh command to list every Wi-Fi network saved on this PC and print its password. It shows only networks this computer has connected to before. It cannot reveal the password of a network you have never joined.

How to use it

  1. Download and unzip the file.
  2. Right-click the .bat file and choose Run as administrator.
  3. Read the list of network names and passwords.

Requirements

Windows. Run as administrator for best results.

Good to know

  • It only reads data already stored on your own PC. Nothing is sent anywhere.
  • Use it for your own networks, for example to share your home Wi-Fi password with a guest. Do not use it on a computer that is not yours.
  • A similar Python version that lists the same information is on the WiFi Password Viewer page.
