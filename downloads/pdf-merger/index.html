ZERO PDF Merger

Join every PDF in a folder into one file, offline.

Type: Python scriptWorks on: Windows, macOS, LinuxVersion: 1.0Size: 1.4 KBPrice: Free

Download ZERO-PDF-Merger.py

What it does

Finds all PDF files in the same folder as the script, joins them in alphabetical order and saves the result as merged.pdf. Nothing is uploaded anywhere, the script has no network code.

How to use it

  1. Install Python 3, then run pip install pypdf once.
  2. Put the script and the PDFs you want to join in one folder.
  3. Name the PDFs so they sort the way you want, for example 01-cover.pdf, 02-report.pdf.
  4. Run the script. The combined file appears as merged.pdf.

Requirements

Python 3 and the pypdf library (pip install pypdf).

Good to know

  • A PDF that has a password is skipped, unless the password is blank. The tool cannot remove passwords it does not know.
  • Running it again overwrites the previous merged.pdf, so move it away if you want to keep it.
  • Bookmarks and form fields in very complex PDFs may not carry over perfectly.

Is it safe?

Read the script first: it is plain text and takes a minute. Only run files you trust, and check the SHA-256 below matches what you downloaded.
