ZERO Auto-Cleaner

Delete temporary and cache files to free up disk space.

Type: Python scriptWorks on: Windows, LinuxVersion: 1.0Size: 1.2 KBPrice: Free

Download ZERO-Auto-Cleaner.py

What it does

Empties temporary and cache folders. On Windows that is your user Temp folder, the system Temp folder and the Internet cache. On Linux it is ~/.cache and /tmp. It prints how much space it freed. Documents, photos and downloads are not touched.

How to use it

  1. Install Python 3.
  2. Close your browser and other apps first, so fewer files are locked.
  3. Run the script and wait for the total to appear.
  4. Restart the computer if you like.

Requirements

Python 3. No extra libraries.

Good to know

  • Deleted files do not go to the Recycle Bin. They are gone.
  • Files in use are skipped.
  • Apps rebuild their caches afterwards, so the first launch can be a little slower and you may be signed out of some apps.
  • The amount of space you free depends entirely on your machine. Some people free a few GB, others only a few MB.
  • On Linux, only use it when you know what /tmp is being used for on your machine.
